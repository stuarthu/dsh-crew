# ADR 0012：「形状」写成任务小节里的一条 bullet，紧跟「里程碑」

- **状态**：已采纳（推荐），2026-08-21
- **决定人**：architect（`paired-engineers` 作业，拆任务时撞上）。CRD 0014 要求任务表带
  「形状」；**它写在哪一行、写成什么，没有人要求过**，所以它是 ADR。
- **落在哪里**：`roles/architect.md`（T-58）、`roles/pm.md`（T-56）。
  样例在 `docs/design/tasks.md` 本作业那一节（T-51 起，每一节都带）。

## 选择是什么

CRD 0012 第 11 条和 CRD 0014 第 2 条都说「哪些任务走双人写在 `docs/design/tasks.md` 的任务行
里」。但这个仓库的 `docs/design/tasks.md` **不是一张表**——它是**一节一个任务**，每节几条
bullet 加一张 DoD 表格。「行」和「栏」这两个词在这里没有直接对应的东西。所以要定：
形状这个信息放在哪。

## 看过的三个选项

| 选项 | 好处 | 代价 / 为什么输 |
| --- | --- | --- |
| **A（推荐）一条 bullet，紧跟「里程碑」，在「拥有的文件」之前**：`- **形状**：单人（solo）` 或 `- **形状**：双人（pair）——接口 ADR：<路径>` | **顺序就是依赖顺序。** 形状决定「拥有的文件」长什么样：单人是一份清单，双人必须拆成 A 的和 B 的两栏（CRD 0013 第 6 条）。读者在读文件清单之前就知道该期待哪一种，engineer 也一样。而且它和现有小节形状一致，一条 bullet，不动结构 | 它不是一张能一眼扫完的总表：想知道「这个作业有几个双人任务」，得翻过每一节 |
| **B 在文件顶部另做一张总表**，一行一个任务，带形状栏 | 一眼扫完全局 | **同一件事有了两个家**，而这个仓库刚为这件事付过学费：`CRD 0010` 废掉全局编号的平表，理由正是「平表没人跟着更新」，而它的三条证据就是过期、矛盾、指向被删的目录。再加一张总表，就是把刚扔掉的东西捡回来 |
| **C 写进 DoD 一节里面** | 不新增结构 | CRD 0014 已经**明确否掉过**这个位置：DoD 一节只讲「done 是什么意思」，装设计细节会把它撑歪；而且 DoD 一节里的字没有「只有 architect 能改」这道守卫。这里再选一次就是无视那份 CRD |

## 决定

**选 A。** 位置固定为：

```
## T-NN — <一句话>

- **Verdicts**：…
- **里程碑**：M1
- **形状**：单人（solo）
- **拥有的文件**：…
```

双人任务的形状那一行**必须同时给出它的接口 ADR 路径**，因为那份 ADR 是 A 和 B 唯一的对齐点
（CRD 0014 第 3 条）；而「拥有的文件」那一行**必须拆成 A 的和 B 的两栏，两边不许重叠**
（CRD 0013 第 6 条）。这两件事写在同一处，engineer 拿到任务时一眼就知道自己是哪一半。

## 英文里这个字段写成 `**Shape**`（第二轮补的）

上面那个样子是**中文任务表**里的写法（`docs/design/tasks.md` 是中文的）。但这份 ADR 落在
`roles/pm.md` 和 `roles/architect.md` 上，**那两个文件是英文的，一个中文字符都没有**，而且
随 npm 包发到用户手里。所以在那两份 persona 里，这个字段写成 `**Shape**`，两个值 `solo`
和 `pair`。

钉的是**加粗的字段名**，不是小写的 shape：`shape` 这个词在 `roles/pm.md` 里今天有 11 处
散文、在 `roles/architect.md` 里有 6 处，钉它等于钉不到东西。验法：
`grep -n '\*\*Shape\*\*' roles/pm.md`、`grep -n '\*\*Shape\*\*' roles/architect.md`。

## 为什么「形状」在「Verdicts」下面而不是上面

`Verdicts` 那一行有一个机器检查（`tools/verify-tasks.mjs`），它要求**每节恰好一行**、
四个键齐全。把它留在紧跟标题的第一条，和这个文件现有的 43 个小节保持一致，检查和读者
都不用适应两种排法。形状是给人读的，排在它后面。

## 代价

- **想知道「这个作业有几个双人任务」要翻全文。** 真代价，接受它：PM 在里程碑评审时报这个
  数字，那是它的活，不是文件的活。
- **本作业自己一个双人任务都没有**（十二个任务全单人形状），所以「双人那一栏」的写法在本作业里
  **一次都不会被真正用到**。样例只出现在 `roles/architect.md` 的说明里。这是它第一次真上场
  之前唯一的检验机会不存在的意思——写清楚，不装作已经验过。
