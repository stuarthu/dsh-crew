## What to do

The folder holding `state.json` moves **inside** the repository, to
`<repo>/.dsh-crew/jobs/<job-slug>/`. The folder is **still single-use**: it is ignored,
never staged, never committed, and dropped whole when the job ends. The move buys the
per-job path and the restart notice, not a record.

The job folder holds **four** single-use things. Three move with it — `state.json`, QA's
plan `<task-id>-plan.md`, and the `Q-` files in `inbox/`. The fourth does not: a test run's
output is not a file at all, in the repository or outside it.

The mechanism is `.git/info/exclude`, not the project's `.gitignore`: the line says where
**this crew** puts progress, not what the project builds, and `info/exclude` is shared by
every worktree, so a paired task's two trees see one rule.
